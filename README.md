
# Embedded Systems Journey 

Welcome to my **Embedded Systems learning journey**.

This repository documents my progress as I learn how embedded systems work — from electronics and microprocessor fundamentals to Embedded C, microcontrollers, communication protocols, RTOS concepts, and real-world projects.

My goal is not just to learn how to program a microcontroller, but to understand **what is happening underneath the code and hardware**.

---

## 🎯 Goal

Build a strong foundation in Embedded Systems by combining:

* Electronics fundamentals
* C and Embedded C
* Microprocessor architecture
* Microcontroller architecture
* GPIO, ADC, PWM and timers
* Interrupts
* UART, I2C, SPI and CAN
* Wi-Fi and Bluetooth
* RTOS concepts
* Debugging
* Hardware interfacing
* Embedded system design
